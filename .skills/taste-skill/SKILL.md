# taste-skill: The Anti-Slop Frontend Skill for AI Agents
Installed from https://github.com/leonxlnx/taste-skill

## Key Principles & Anti-Default Rules:
1. **Design Read First**: Declare design read before output.
2. **Color Lock & Palette**: Use curated, harmonious color palettes (Earthy Botanical Modern `--ph-*` tokens). No random colors or inconsistent accents.
3. **Typography Discipline**: High readability, proper line heights, descender clearance on italic/display type.
4. **Layout Rhythm & Spacing**: No repetitive 3-card rows. Use asymmetric grids, bento cards, scroll-aligned layouts, clean spacing.
5. **No Emojis**: Replace all emojis with inline themeable SVG vector icons.
6. **No Em-Dashes (`—`)**: Remove em-dashes completely. Use proper punctuation or hyphens.
7. **Accessibility & Contrast**: High-contrast text on all buttons and backgrounds (WCAG AA min).
8. **Responsive Mechanics**: Full mobile and desktop stability (`min-h-[100dvh]`, no viewport overflow).
